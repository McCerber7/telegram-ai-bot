# Telegram-бот автоответчик с ИИ (Claude / Mistral)

Бот отвечает на входящие сообщения, используя ИИ-провайдера на выбор:
Anthropic Claude или Mistral AI. Помнит контекст диалога и сохраняет
историю на диск, поэтому переживает перезапуск.

## Возможности
- Переключение провайдера одной строкой в `.env` (`PROVIDER=claude|mistral`)
- Память диалога (последние N сообщений, N настраивается)
- Роль/характер бота задаётся в отдельном файле `prompt.txt` — без правки кода
- Индикатор «печатает…» пока модель думает
- Автообрезка длинных ответов под лимит Telegram (4096 символов)
- Обработка ошибок API — бот не падает, вежливо извиняется
- `ECHO_MODE=1` — проверка связи с Telegram без затрат на ИИ
- История хранится в `data/history.json` (атомарная запись)

## Структура
```
config.py     — загрузка и валидация .env
providers.py  — Claude / Mistral / echo-провайдеры (общий интерфейс)
memory.py     — память диалогов + сохранение на диск
main.py       — aiogram-бот и обработчики
prompt.txt    — системная роль бота (редактируется свободно)
```

## Установка

1. Создайте бота у [@BotFather](https://t.me/BotFather) → получите токен.
2. Получите API-ключ провайдера:
   - Claude: <https://console.anthropic.com/settings/keys>
   - Mistral: <https://console.mistral.ai/api-keys>
3. Установите зависимости:
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
4. Скопируйте шаблон настроек и заполните:
   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```
   Минимум нужно `BOT_TOKEN` и ключ выбранного провайдера.

## Запуск
```powershell
python main.py
```
Остановка — `Ctrl+C`.

### Проверка без затрат на ИИ
Поставьте в `.env` `ECHO_MODE=1` и запустите бота — он будет отвечать эхом.
Так проверяется, что токен бота верный и связь с Telegram есть.

## Тесты
```powershell
python -m pytest -q
```

## Настройка роли
Откройте `prompt.txt` и опишите характер и правила бота. Изменения
подхватываются при следующем запуске.

## Провайдеры и модели
- Claude по умолчанию: `claude-opus-5-5`, `effort=low`, адаптивное мышление,
  серверный fallback при отказе по безопасности.
- Mistral по умолчанию: `mistral-small-latest`.
Модели и параметры меняются в `.env` без правки кода.
